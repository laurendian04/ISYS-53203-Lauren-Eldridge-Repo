# Lauren Eldridge - Analytics & Strategy Portfolio

Personal portfolio created for ISYS 53203: Development with Digital Innovation.

## Pages

- `index.html` - refined portfolio
- `links.html` - mobile-first networking page
- `baseline.html` - separate resume-only first iteration

## Run locally

Open `index.html` in a browser. The project is a static site with no build step or external dependencies.

## GitHub Pages

This repository is ready for GitHub Pages from the `main` branch and repository root. In the repository settings, select **Pages**, choose **Deploy from a branch**, and use `main` / `(root)`.
